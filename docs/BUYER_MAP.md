# Aviation Recovery — Buyer Map

_Last reviewed: 2026-09-04_

## Purpose

Convert target accounts into a contactable commercial queue without guessing personal contact data or overstating known leakage.

The default buying motion is:

**economic owner -> operational/technical co-owner -> bounded recovery scan -> evidence request -> reconciled candidate register -> human-reviewed claim package -> verified settlement.**

## Commercial routing rule

For every account, prefer this order:

1. verified direct professional route to the named buyer;
2. verified direct route to the functional co-owner;
3. company procurement/vendor route if appropriate;
4. public IR/corporate contact only to request internal routing;
5. never guess an email address from a naming pattern.

## Qualification before any real outbound

Do not send until these fields are true:

- named current buyer verified;
- one current account-specific economic signal verified;
- one bounded pilot hypothesis exists;
- outreach contains no allegation of missed claims;
- CTA is a short qualification call, not a broad demo;
- sender identity/mailbox is explicitly approved for real outbound.
