# AERVIND — Real Outreach Hold

Status: **ACTIVE**

Owner instruction: do not send anything to any real person or organization until the founder explicitly changes this status.

## Applies to

- airlines and operators;
- lessors, consultants, lawyers, MRO advisers and other partners;
- suppliers and procurement teams;
- any real external recipient used only for a mail test;
- LinkedIn/direct-message/contact-form outreach;
- email sequences and CRM enrollment that can result in a send;
- external claim packages or counterparty lifecycle messages.

## Still allowed

- repository work;
- deterministic tests and synthetic E2E;
- public-source research;
- private buyer briefs and route mapping;
- unsent email/proposal/video drafts;
- website and DNS infrastructure work;
- mail-domain DNS verification that does not transmit a message to a real recipient;
- inbound monitoring and response drafting without sending.

## Lift condition

Only a new explicit founder instruction authorizing real outreach changes this status. Product readiness, a verified domain, a live website, a discovered buyer address, a prepared draft or an earlier general autonomy instruction do **not** implicitly lift the hold.
