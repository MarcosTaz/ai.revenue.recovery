## Commercial launch sequence

1. Secure `aervind.com`.
2. Publish the existing static landing page; no paid hosting tier is required by the current design.
3. Verify the Portuguese activity classification before rendering the first paid service.
4. Begin account-based outreach through compliant, verified routes.
5. Prioritize a bounded Recovery Scan over software / SaaS selling.
6. Run discovery; issue the proposal only when the buyer and scope are real.
7. Receive customer evidence only under the agreed confidentiality / handling boundary.
8. Execute the deterministic recovery workflow.
9. Report identified, blocked, review-required, claim-ready and settled value separately.
10. Reassess incorporation only when buyer requirements or actual operating economics justify it.

## No-spend rule before proof

Do not add paid ads, paid SaaS infrastructure, secondary domains, self-service billing, SSO, deep integrations or a Portuguese company merely for appearance before real commercial evidence requires them.
