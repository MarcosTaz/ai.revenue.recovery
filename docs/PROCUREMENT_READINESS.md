| Field | Status | Rule |
| --- | --- | --- |
| Legal supplier name | REQUIRED | Real individual legal name |
| Professional / tax address | REQUIRED | Match actual tax / professional records |
| VAT / tax number | REQUIRED | Real Portuguese NIF / VAT identity |
| Activity classification | REQUIRED | Must cover the service actually provided |

| Authorized customer signatory / PO owner | CUSTOMER-SPECIFIC | Use actual authority / procurement flow |
| Bank / IBAN | PAYMENT STAGE | Real account details only |
| Insurance | IF REQUIRED | Declare actual coverage only |

**GO now:** internal product work, public-source research, private briefs, unsent drafts, synthetic proof, procurement preparation, and infrastructure work that does not message a real person.

**HOLD now:** all real commercial outreach, supplier registration submissions, contact forms, LinkedIn messages, partner/prospect messages, real-recipient email tests and external claim/counterparty messages.

**GO for a paid engagement only after:**

1. the founder explicitly lifts the real-outreach hold;
2. a real buyer voluntarily enters the process through an authorized route;
3. supplier activity/tax facts are verified;
4. buyer entity, contract/SOW and invoice treatment are verified;
5. customer procurement/security requirements are satisfied truthfully.

**NO-GO** if progression requires inventing corporate facts, misusing investor/customer-service channels, violating the active no-send hold, applying an unverified tax/VAT treatment, or claiming legal/audit/security certification that AERVIND does not hold.
